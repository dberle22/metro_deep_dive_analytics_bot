The analysis folder contains short form analysis for quick insights. The goal is to build manual insights that can be turned into easy writing prompts. The questions and analyses defined here may be deeper or more tuned than our chatbot library so this folder can also act as a leading indicator for the chatbot. We will structure this into folders for each analysis. Inside each folder we will have a Markdown file with the prompt and some notes about the outputs, the SQL to generate the required data, a .R to visualize the charts, and the chart stored.
